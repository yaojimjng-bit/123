# SqueezeLab 图片压缩工具

一个无需安装依赖的本地图片压缩工具，直接打开 `index.html` 就能使用。
当前已经带上默认品牌 `SqueezeLab` 和 logo，适合直接对外分享。

## 功能

- 批量选择或拖拽上传图片
- 调节压缩质量
- 限制最大宽度和高度
- 输出为原格式、JPEG、WebP 或 PNG
- 页面内预览压缩结果
- 单张下载或全部下载

## 使用方式

1. 打开 `index.html`
2. 选择图片或直接拖拽到页面
3. 调整质量、尺寸和输出格式
4. 点击“开始压缩”
5. 下载生成后的图片

## 说明

- 所有处理都在浏览器本地完成，不会上传到服务器。
- `JPEG` 和 `WebP` 通常更适合明显缩小体积。
- 导出 `JPEG` 时，透明区域会填充为你设置的背景色。
- 如果你要换成自己的品牌，优先改 `index.html` 里的品牌文案，并替换 `assets/logo.svg`。
